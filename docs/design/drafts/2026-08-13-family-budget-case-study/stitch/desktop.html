Three Stories

1. 소스 추출 및 정합성 (Source Extraction)

데모용 중복 UI 제거 및 SHA 매니페스트 기반의 패키지 관리를 통해 코드 베이스의 무결성을 유지했습니다. 단일 진실 공급원(Single Source of Truth) 원칙을 적용하여 유지보수 오버헤드를 극적으로 줄였습니다.

2. 런타임 어댑터 전환 (Runtime Adapter)

소스 별칭(Alias)을 패키지 export로 교체하여 비공개 API 동작을 보존했습니다. 환경 변수에 따른 의존성 주입을 통해 퍼블릭 런타임에서는 합성 데이터를, 프라이빗 런타임에서는 실제 API를 호출하도록 설계했습니다.

3. 릴리스 품질 확보 (Release Quality)

엄격한 반응형 및 접근성 테스트를 통해 CSS 레이아웃 결함을 제거했습니다. 크로스 브라우징 및 다양한 디바이스 환경에서의 일관된 렌더링을 보장하기 위해 자동화된 CI 파이프라인을 구축했습니다.

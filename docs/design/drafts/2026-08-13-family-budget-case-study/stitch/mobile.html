Synthetic Budget Vertical Slice

System Design

Architecture Boundary

System Boundaries: Prevention of private data leaks

The architecture ensures strict isolation between the public-facing UI components and the private data environment, utilizing adapter patterns to inject synthetic data for demonstration purposes without compromising security.

Implementation

Three Stories

01

Decoupling the UI

Refactoring the presentation layer to accept injected state providers rather than hardcoded API dependencies.

02

Synthetic Data Generation

Creating realistic, localized mock data that behaves predictably within the demonstration environment.

03

Build Pipeline Configuration

Establishing separate deployment tracks for the private application and the public portfolio asset.
